# Contributing

Thanks for considering a contribution to InvoiceKit!

## Ways to help
- Report a bug or suggest a feature through GitHub Issues.
- Improve mobile layout and accessibility.
- Add translations or currency formatting options.
- Improve validation and invoice print styling.

## Before opening a pull request
1. Keep the app dependency-free unless a dependency is clearly justified.
2. Test the invoice editor on desktop and mobile widths.
3. Verify item calculations, tax calculations, draft save/load, and print preview.
4. Keep user invoice data local; do not add analytics or remote data collection without clear opt-in.

## Development

Open `index.html` directly or run `python -m http.server 8000`.
