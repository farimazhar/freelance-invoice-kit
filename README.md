InvoiceKit is a free, simple, and responsive invoice generator designed for freelancers, developers, designers, and small businesses.

Create professional invoices, calculate taxes automatically, and save your invoices as PDF — all directly in your browser.

🚀 Features

- 🧾 Generate professional invoices instantly
- 📄 Print or save invoices as PDF
- 💰 Automatic subtotal, tax, and total calculations
- 🌍 Multiple currency support:
  - USD ($)
  - EUR (€)
  - GBP (£)
  - PKR (Rs)
  - AED
  - INR (₹)
- 👤 Add business and client information
- ➕ Add or remove invoice items
- 📅 Set invoice issue and due dates
- 💾 Save and load invoice drafts
- 📱 Fully responsive design
- 🔒 Privacy-friendly — no signup or backend required
- ⚡ Lightweight and dependency-free

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

📸 How to Use

1. Download or clone this repository.
2. Open "index.html" in your browser.
3. Enter your business and client details.
4. Add services, quantities, and prices.
5. Select your preferred currency.
6. Add tax if required.
7. Click Download / Print PDF.
8. Save your professional invoice as PDF.

💻 Installation

Clone the repository:

git clone https://github.com/farimazhar/freelance-invoice-kit.git

Open the project folder:

cd freelance-invoice-kit

Run locally:

python -m http.server 8000

Visit:

http://localhost:8000

🔐 Privacy

InvoiceKit processes invoice information directly in your browser.

- No account required.
- No backend server.
- No external database.
- Drafts are stored locally only when you choose Save Draft.

Your invoice data stays on your device.
